## 新增需求

### 需求:SSE 协议解析器框架
系统必须提供可扩展的 SSE 协议解析器框架，支持下拉切换不同的解析器。

#### 场景:解析器下拉菜单显示
- **当** 响应是 SSE 流式响应
- **那么** 结果展示区显示解析器下拉菜单
- **当** 响应是非流式响应
- **那么** 不显示解析器下拉菜单

#### 场景:切换解析器
- **当** 用户从下拉菜单选择不同的解析器
- **那么** 解析视图立即切换显示所选解析器的累积结果
- **当** 正在接收 SSE 流时切换解析器
- **那么** 所有已注册解析器仍在同时接收帧，切换只是改变显示的解析器

#### 场景:新增解析器扩展点
- **当** 开发者需要新增解析器（如千问 DashScope）
- **那么** 只需实现 SSEParser 接口并注册到解析器 Map 中
- **当** 解析器注册后
- **那么** 下拉菜单自动包含新解析器选项

### 需求:OpenAI SSE 协议解析器
系统必须实现 OpenAI Chat Completions SSE 协议解析器。

#### 场景:解析 OpenAI delta.content
- **当** SSE 帧 payload 是 JSON 且包含 choices[0].delta.content
- **那么** 解析器提取 content 字段并追加到累积字符串
- **当** 多个 delta 帧到达
- **那么** 每个 delta.content 按到达顺序依次追加

#### 场景:处理 [DONE] 帧
- **当** SSE 帧 payload 是字符串 "[DONE]"
- **那么** 解析器标记 isComplete() 为 true，不再处理后续帧

#### 场景:忽略非 JSON 帧
- **当** SSE 帧 payload 无法解析为 JSON
- **那么** 解析器静默忽略该帧，不抛出错误，不影响累积结果

#### 场景:累积视图实时更新
- **当** OpenAI 解析器收到 delta.content
- **那么** 累积视图立即显示追加后的完整文本
- **当** 流结束且用户选中 OpenAI 解析器
- **那么** 显示完整的累积文本（所有 delta.content 拼接结果）

#### 场景:解析器同时运行
- **当** SSE 流正在接收
- **那么** 所有已注册的解析器同时收到每一帧的 payload 字符串
- **当** 用户切换到其他解析器
- **那么** 立即显示该解析器已累积的结果（无需重放历史帧）
